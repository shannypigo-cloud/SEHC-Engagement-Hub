Learning Center

Admin & Supervisor Quick Start

1Create & manage users
2Review Bingo submissions
3Run contests & awards

Use this page as the operational guide for the Engagement Hub. It is designed for administrators and supervisors.

Daily Bingo

Employees submit a qualifying activity with an Account / Reference Number. Supervisors verify and approve it. Approved tickets immediately feed the Daily Bingo leaderboard and Grand Draw.

Contests & Wallet

Ad Hoc Contests can award Wallet Points, Raffle Tickets, or both. Wallet Points are redeemable in the Reward Store. Raffle Tickets increase an employee's chances in the Grand Draw.

Grand Draw

Approved Bingo tickets and eligible contest raffle tickets create the draw pool. The draw can run manually or automatically at the scheduled time.

Security & User Management

Administrators create accounts and manage roles. Supervisors have limited permissions. Temporary passwords must be changed at first login. Never place passwords in spreadsheets or emails.

Monthly Eligibility

Daily Bingo and Grand Draw eligibility is based on the previous month's performance metrics. Missing metrics remain Pending Verification and are not eligible to participate.

Quality Gate Settings

Administrators can change the minimum thresholds. Supervisors can view them but cannot modify them.

Monthly Employee Metrics

Eligibility Roster

If Connect Time and Compliance are blank, the employee is waiting for those prior-month metrics to be entered.

User Management

Create Account

Administrators create new Engagement Hub accounts. Employee ID is generated automatically based on role. New users receive a temporary password and must change it on first sign-in.
